The native core excludes NaNs and compares ordered IEEE FP32 keys. A monotone bit mapping places all NaNs above +inf, merges the two zero signs and preserves all other ranks, including subnormals. This is an exact rank transformation, with no score quantization. Original scores are unchanged. The output kernel restores ascending integer order for short rows and descending original-value rank for long rows, then translates indices and marks -inf as invalid. Equal-score ID membership may differ; repeated native TorchTopK itself does not guarantee fixed membership on ties.
